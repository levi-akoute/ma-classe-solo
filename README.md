# Ma Classe : calculateur de moyenne

Petit projet fil rouge du cours Technologies DevOps (Licence 2).
Il calcule la moyenne pondérée d'un élève à partir d'un fichier de notes.

## Contenu

- `index.html` : page d'accueil du projet
- `style.css` : mise en forme
- `moyenne.py` : calcul de la moyenne pondérée
- `test_moyenne.py` : tests automatiques
- `donnees/notes.csv` : exemple de notes

## Lancer le calcul

    python3 moyenne.py        (Ubuntu / WSL / Linux)
    python moyenne.py         (Windows PowerShell)

## Lancer les tests

    python3 -m unittest       (Ubuntu / WSL / Linux)
    python -m unittest        (Windows PowerShell)
